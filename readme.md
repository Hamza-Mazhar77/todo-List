## To-Do List Web Application:
A simple and responsive To-Do List application built using HTML, CSS, and JavaScript. This project allows users to add, display, and delete tasks while automatically saving them in the browser using Local Storage, so tasks remain available even after refreshing the page.

## Features:
- Add new tasks
- Assign a due date to each task
- Delete completed or unwanted tasks
- Automatically saves tasks using Local Storage
- Tasks remain after page refresh
- Simple and clean user interface

## Technologies Used:
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How It Works:
1. Enter a task name.
2. Select a due date.
3. Click the Add button.
4. The task is displayed in the list.
5. Tasks are automatically saved in the browser.
6. Click Delete to remove any task.

## Getting Started:
1. Download or clone the repository.
```bash
git clone https://github.com/your-username/todo-list.git
```
2. Open the project folder.
3. Double-click todoList.html or open it in your preferred web browser.
4. No additional installation or dependencies are required.
